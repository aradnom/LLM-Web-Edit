# Something about a website annoying you? Fix it.

This is a simple Firefox extension and server that passes a snapshot of the current website to Claude Code along with a request to change whatever you like about the current page you're looking at. Ask it to remove banner ads. Ask it to add a new type of sorting to a dropdown. Ask it to turn the header into a sidebar. Whatever.

Requires Claude Code to be installed and accessible in the terminal.

Use at your own risk.
